Learning Academy

Welcome to the official syllabus for Sassembly and SanOS. Select a module below to begin your journey into zero-latency, language-native software engineering.

Tier 1 · प्रारम्भिक स्तर (Basic Fundamentals)

१. The Sanskrit Sentence
Understand the grammatical structure of Sassembly instructions instead of traditional opcodes.
२. The 5 Kāraka Sigils
Learn how to define verbs, subjects, objects, and instruments natively.
३. The 32 RV64 Registers
Explore how Sanskrit maps directly onto the 64-bit RISC-V hardware architecture.
४. Sanskrit Numerals
Master Devanagari numeric literals for immediate values and memory offsets.
५. Directives & Sections
Define executable code (.पाठः) and static data (.दत्तांशः) boundaries.

Tier 2 · मध्यम स्तर (Intermediate)

६. Arithmetic & Logic
Perform mathematical computations and bitwise operations.
७. Memory & Extents (व्याप्ति)
Understand pointers, heap allocation, and the concept of Vyāpti.
८. Control Flow & Branches
Implement conditionals, loops, and jump tables.
९. Akṣara Normalisation
Parse Unicode and resolve complex conjuncts across the Seema bridge.
१०. Calling Conventions
Manage ABI compliance, stack frames, and recursive functions.

Tier 3 · प्रौढ स्तर (Advanced)

११. Boot Proofs vs U-Mode
Navigate cryptographic execution modes and privilege rings.
१२. Atomic Operations
Implement hardware-enforced atomics (`यम्`) for concurrent processing.
१३. 64-bit Floating Point
Master IEEE 754 precision math in Sassembly.
१४. 3 Core System Elements
Understand the Scheduler, Memory Manager, and HAL.
१५. Native Applications
Compile fully independent, dynamically linked executables.
१६. Zero-Mass Computing
Eradicate idle memory overhead using event-driven architectures.

Tier 4 · प्रायोगिक-कार्याणि (Practical Applications)

१७. High-Grade Databases
Engineer zero-latency, concurrent ACID databases using B-Trees and memory-mapped files.
१८. Server Engines (Nginx-like)
Construct highly concurrent, asynchronous HTTP servers running on single cores.
१९. Web Apps & Payments API
Bridge REST endpoints across the Seema boundary to Stripe, PayPal, and external APIs.
